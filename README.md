# Customer Shopping Behavior Analysis

## Overview

This project analyzes customer shopping behavior using transactional data from **3,900 purchases** across different product categories.

The objective is to identify customer spending patterns, product preferences, customer segments, discount usage, subscription behavior, and other business insights using **Python, SQL, PostgreSQL, and Power BI**.

The project follows an end-to-end data analytics workflow:

**Data Loading → Exploratory Data Analysis → Data Cleaning → Feature Engineering → SQL Analysis → Power BI Dashboard → Business Insights & Recommendations**

---

## Dataset

The dataset contains **3,900 rows and 18 columns**.

### Key Data Fields

* Customer demographics — Age, Gender, Location
* Purchase information — Item Purchased, Category, Purchase Amount
* Product attributes — Size, Color, Season
* Customer behavior — Previous Purchases, Frequency of Purchases
* Customer feedback — Review Rating
* Subscription information — Subscription Status
* Discount information — Discount Applied, Promo Code Used
* Order information — Shipping Type, Payment Method

The dataset initially contained **37 missing values in the Review Rating column**. These were handled during the data-cleaning process.

### 3. Data Cleaning

The following cleaning steps were performed:

#### Handling Missing Values

Missing review ratings were filled using the **median rating within each product category**.

```python
df["Review Rating"] = df.groupby("Category")["Review Rating"].transform(
    lambda x: x.fillna(x.median())
)
```

#### Standardizing Column Names

Column names were converted to lowercase and spaces were replaced with underscores.

```python
df.columns = df.columns.str.lower()
df.columns = df.columns.str.replace(" ", "_")
```

The purchase amount column was also renamed for easier use in SQL:

```python
df = df.rename(
    columns={"purchase_amount_(usd)": "purchase_amount"}
)
```

These steps made the dataset easier to work with throughout the analysis.

---

### 4. Feature Engineering

Two additional features were created.

#### Age Group

Customers were divided into four age groups:

* Young Adult
* Adult
* Middle Aged
* Senior

```python
labels = ["Young Adult", "Adult", "Middle Aged", "Senior"]

df["age_group"] = pd.qcut(
    df["age"],
    q=4,
    labels=labels
)
```

#### Purchase Frequency in Days

Purchase frequency categories were converted into an approximate number of days.

Examples:

* Weekly → 7 days
* Fortnightly → 14 days
* Monthly → 30 days
* Quarterly → 90 days
* Annually → 365 days

## SQL Analysis

After cleaning and transforming the data in Python, the dataset was loaded into **PostgreSQL** for SQL-based business analysis.

The SQL analysis focused on answering practical business questions such as:

1. What is the total revenue generated by male vs. female customers?
2. Which customers used discounts but still spent above the average purchase amount?
3. Which are the top 5 products based on average review rating?
4. How does average purchase amount differ between Standard and Express shipping?
5. How do subscribers compare with non-subscribers in spending and revenue?
6. Which products have the highest percentage of discounted purchases?
7. How many customers belong to New, Returning, and Loyal segments?
8. What are the top 3 most purchased products within each category?
9. Are repeat buyers more likely to subscribe?
10. What is the revenue contribution of each age group?

These queries use SQL concepts including:

* `GROUP BY`
* `ORDER BY`
* `CASE`
* Aggregate functions
* Subqueries
* Common Table Expressions (CTEs)
* Window functions
* `ROW_NUMBER()`

The project report documents these business questions and their analysis.

## Database Integration

The cleaned Pandas DataFrame was loaded into a PostgreSQL database using **SQLAlchemy**.

```python
from sqlalchemy import create_engine

engine = create_engine(
    "postgresql+psycopg2://username:password@localhost:5432/customer_behaviour"
)

df.to_sql(
    "customer",
    engine,
    if_exists="replace",
    index=False
)
```

This created the `customer` table, which was then used for SQL analysis.
